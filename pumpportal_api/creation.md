# Pump.fun Token Creation
You can create tokens via the pump.fun API.
There is no additional fee for token creation. The standard trading fee is applied to the initial dev buy.
The old pump.fun/api/ipfs endpoint is no longer supported. To create coins programatically, you must now upload metadata to an IPFS service. We have updated our examples to use [Pinata IPFS](https://pinata.cloud/). To use our token creation examples, create a free Pinata account and API key, copy the JWT key, and paste it into the examples below:
