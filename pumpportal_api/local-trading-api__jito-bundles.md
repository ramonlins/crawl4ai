# Jito Bundles
The Trading API can be used to construct Jito bundles. Build trades as you otherwise would, except the JSON body in your request to PumpPortal should be an _array_ of objects, as shown in the example below.
See [Token Creation](https://pumpportal.fun/creation#jito-bundle-examples) for more advanced examples creating tokens with bundles.
### Examples[​](https://pumpportal.fun/local-trading-api/jito-bundles/#examples "Direct link to Examples")
