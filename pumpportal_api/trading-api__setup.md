# Getting Started
### Step 1: Generate a Lightning Wallet & API Key[​](https://pumpportal.fun/trading-api/setup/#step-1-generate-a-lightning-wallet--api-key "Direct link to Step 1: Generate a Lightning Wallet & API Key")
If you would like to sign and send transactions with your own wallet instead of a Lightning wallet, use the Local Transaction API.
Click the button below to generate a new Solana wallet and linked API key.
You will then be able to use your API key to trade with the funds in the linked wallet.
Create Wallet & API Key
Copy Wallet Public Key 
Copy Wallet Private Key 
Copy API Key 
**SECURELY SAVE YOUR PRIVATE KEY** : You can withdraw funds by adding your private key to any Solana wallet software such as Phantom. Anyone with access to your private key can do the same.
**SECURELY SAVE YOUR API KEY** : Anyone with your API key can trade using the funds in your wallet.
Your keys will disappear upon navigating away from this page OR clicking the button again to create a new API key and wallet.
**KEYS CAN NOT BE RECOVERED IF LOST**.
### Step 2: Fund Your Wallet[​](https://pumpportal.fun/trading-api/setup/#step-2-fund-your-wallet "Direct link to Step 2: Fund Your Wallet")
Just send any amount of SOL to the address (public key) of the wallet you created above.
That's it! You can now trade with the funds in your wallet using the API. Continue the [next page](https://pumpportal.fun/trading-api/) to read how.
You may create as many wallets as you like. If you are building a trading service for multiple users, you will probably want to use our API to create a new wallet _per user_.
