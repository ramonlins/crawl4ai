# Source: https://www.helius.dev/docs/api-reference/rpc/websocket-methods

This is a comprehensive list of all WSS methods for the Solana RPC. For detailed information on each method including parameters, results, and examples, please refer to the individual API reference pages.
New: All Solana WSS methods are now served by the same infra that powers LaserStream to deliver up to 200 ms faster responses.
## Supported WebSockets Methods
## [accountSubscribe Subscribe to an account to receive notifications when the lamports or data for a given account public key changes ](https://www.helius.dev/docs/api-reference/rpc/websocket/accountsubscribe)
## [accountUnsubscribe Unsubscribe from account change notifications ](https://www.helius.dev/docs/api-reference/rpc/websocket/accountunsubscribe)
## [logsSubscribe Subscribe to transaction logging ](https://www.helius.dev/docs/api-reference/rpc/websocket/logssubscribe)
## [logsUnsubscribe Unsubscribe from transaction logging ](https://www.helius.dev/docs/api-reference/rpc/websocket/logsunsubscribe)
## [programSubscribe Subscribe to a program to receive notifications when the lamports or data for accounts owned by the program changes ](https://www.helius.dev/docs/api-reference/rpc/websocket/programsubscribe)
## [programUnsubscribe Unsubscribe from program notifications ](https://www.helius.dev/docs/api-reference/rpc/websocket/programunsubscribe)
## [rootSubscribe Subscribe to receive notification anytime a new root is set by the validator ](https://www.helius.dev/docs/api-reference/rpc/websocket/rootsubscribe)
## [rootUnsubscribe Unsubscribe from root notifications ](https://www.helius.dev/docs/api-reference/rpc/websocket/rootunsubscribe)
## [signatureSubscribe Subscribe to a transaction signature to receive notification when the transaction is confirmed ](https://www.helius.dev/docs/api-reference/rpc/websocket/signaturesubscribe)
## [signatureUnsubscribe Unsubscribe from signature confirmation notification ](https://www.helius.dev/docs/api-reference/rpc/websocket/signatureunsubscribe)
## [slotSubscribe Subscribe to receive notification anytime a slot is processed by the validator ](https://www.helius.dev/docs/api-reference/rpc/websocket/slotsubscribe)
## [slotUnsubscribe Unsubscribe from slot notifications ](https://www.helius.dev/docs/api-reference/rpc/websocket/slotunsubscribe)
## Unstable Methods (Not Supported)
These subscription methods are considered unstable and are not supported on Helius. This documentation is provided for reference only.
## [blockSubscribe Subscribe to receive notification anytime a new block is confirmed or finalized ](https://www.helius.dev/docs/api-reference/rpc/websocket/blocksubscribe)
## [blockUnsubscribe Unsubscribe from block notifications ](https://www.helius.dev/docs/api-reference/rpc/websocket/blockunsubscribe)
## [slotsUpdatesSubscribe Subscribe to receive notification anytime a slot is processed, optimized for high performance applications ](https://www.helius.dev/docs/api-reference/rpc/websocket/slotsupdatessubscribe)
## [slotsUpdatesUnsubscribe Unsubscribe from slots updates notifications ](https://www.helius.dev/docs/api-reference/rpc/websocket/slotsupdatesunsubscribe)
## [voteSubscribe Subscribe to receive notification anytime a new vote is observed in gossip ](https://www.helius.dev/docs/api-reference/rpc/websocket/votesubscribe)
## [voteUnsubscribe Unsubscribe from vote notifications ](https://www.helius.dev/docs/api-reference/rpc/websocket/voteunsubscribe)
